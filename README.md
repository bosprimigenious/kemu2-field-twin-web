# 科目二训练场 · 数字孪生演示

浏览器打开 <https://bosprimigenious.github.io/kemu2-field-twin-web/>。

- 手动驾驶：`W/S` 前进·倒车，`A/D` 转向，`Space` 停车。
- 自动驾驶：选项目后点「自动驾驶」，车辆用几何纯追踪跟踪参考线，HUD 实时显示横向偏差。

场地几何取自 `kemu2-field-twin@7418a00` 的 `site.mjs`，用于课堂展示；车辆为 4.47 m × 1.71 m 的参考车型。

`scene-layout.json` 是场景交接数据（区域 ID、平面边界、入口位姿、标线宽度、坡面采样、模型尺寸）。
